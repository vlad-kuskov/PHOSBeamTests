# PHOS Beam Tests

**Analysis of PHOS calorimeter prototype beam-test data at CERN PS and SPS**

Репозиторий содержит макросы на C++ с использованием [CERN ROOT](https://root.cern/) для обработки и визуализации данных пучковых испытаний прототипа электромагнитного калориметра **PHOS** эксперимента **ALICE** с новой электроникой считывания на основе кремниевых фотоумножителей (**SiPM**) Hamamatsu MPPC:

- **S14160-6015PS**;
- **S14160-6010PS**.

Испытания проводились на электронных пучках ускорителей **Proton Synchrotron (PS)** и **Super Proton Synchrotron (SPS)** в CERN в 2023–2024 годах. Основная цель анализа — исследование характеристик прототипа, прежде всего **энергетического и временного разрешения** калориметра с обновлённой электроникой.

## Возможности

- Обработка экспериментальных данных, зарегистрированных системой сбора данных **MIDAS**.
- Работа с сигналами электроники **CAEN** в стандарте **VME**.
- Мониторинг данных, анализ пьедесталов и амплитуд сигналов.
- Калибровка каналов и исследование коэффициентов усиления.
- Построение энергетических спектров и определение энергетического разрешения.
- Анализ временных характеристик и визуализация результатов испытаний на PS и SPS.

## Структура репозитория

```text
PHOSBeamTests/
├── MidasReader/                 # Чтение данных MIDAS от модулей CAEN VME
├── SPS/                         # Макросы анализа и визуализации данных SPS
├── AnalyzeMidas.C               # Обработка данных MIDAS
├── AnalyzeMidas_offline.C       # Офлайн-анализ MIDAS
├── OnlineMonitoring.C           # Мониторинг экспериментальных данных
├── DrawPedestals.C              # Визуализация пьедесталов
├── PedVsTime.C                  # Исследование пьедесталов во времени
├── CalculateADCAmplitude.C      # Анализ амплитуд АЦП
├── CalculateCalibFactor.C       # Расчёт калибровочных коэффициентов
├── GainCalculation.C            # Расчёт коэффициентов усиления
├── CalculateEnergyResolution.C  # Расчёт энергетического разрешения
├── EnergyResolution.C           # Визуализация энергетического разрешения
├── SysEnergyResolution.C        # Анализ систематических неопределённостей
└── CalibrationSys.sh            # Вспомогательный скрипт для калибровки
```

**Корневая директория** содержит преимущественно макросы для анализа результатов испытаний на **PS**. В каталоге [`SPS/`](SPS/) находятся макросы для данных, полученных на **SPS**. Каталог [`MidasReader/`](MidasReader/) содержит компоненты для чтения данных, записанных с помощью MIDAS при использовании электроники CAEN VME.

## Зависимости

- [CERN ROOT](https://root.cern/) — выполнение C++-макросов, обработка гистограмм, аппроксимация и визуализация.
- Компилятор C++ и окружение, совместимые с установленной версией ROOT.
- [MIDAS](https://daq00.triumf.ca/MidasWiki/index.php/Main_Page) — система сбора данных, использовавшаяся во время испытаний; для работы с исходными MIDAS-файлами могут потребоваться соответствующие библиотеки и заголовочные файлы.
- Bash — для запуска вспомогательного скрипта `CalibrationSys.sh`.

Набор необходимых библиотек зависит от выбранного макроса и формата исходных данных.

## Начало работы

Для запуска ROOT-макроса, например расчёта энергетического разрешения для данных PS, используйте:

```bash
root -l -q 'CalculateEnergyResolution.C'
```

Для интерактивного запуска:

```bash
root -l
root [0] .x CalculateEnergyResolution.C
```

Для анализа данных SPS перейдите в каталог `SPS/` и запустите нужный ROOT-макрос аналогичным образом.

> **Важно:** перед запуском необходимо проверить пути к входным ROOT-файлам, номера экспериментальных запусков (*run numbers*), параметры калибровки и имена используемых гистограмм. В некоторых макросах пути к данным и вспомогательным файлам заданы непосредственно в исходном коде. Экспериментальные данные и калибровочные файлы необходимо разместить по ожидаемым путям либо изменить пути в макросах.

## Обработка данных и результаты

Экспериментальные события регистрировались системой **MIDAS** с использованием модулей **CAEN VME**. Компоненты каталога `MidasReader/` предназначены для чтения этих данных. Дальнейший анализ и построение графиков выполняются с помощью макросов CERN ROOT.

При исследовании энергетического разрешения анализируются распределения восстановленной энергии для разных энергий электронного пучка. В частности, в `CalculateEnergyResolution.C` используется гауссова аппроксимация энергетических спектров и определяется относительное разрешение

$$
\frac{\sigma_E}{E} = \frac{\sigma}{\mu},
$$

где $\mu$ и $\sigma$ — среднее значение и стандартное отклонение аппроксимирующей функции. Для описания зависимости разрешения от энергии применяется параметризация

$$
\frac{\sigma_E}{E} = \sqrt{\left(\frac{a}{E}\right)^2 + \left(\frac{b}{\sqrt{E}}\right)^2 + c^2}.
$$

Макросы позволяют визуализировать результаты измерений энергетических и временных характеристик прототипа, а также выполнять вспомогательный калибровочный анализ.
